# Soroban Fleet Registry — Project Description

Soroban Fleet Registry is an open-source indexing and verification service for Soroban CAP-85 externally managed executables on the Stellar network. While CAP-85 allows contract instances to delegate their executable reference to an external owner contract and tag string, maintainers lack native on-chain visibility into which contract instances share a reference, what WASM code is currently resolved, how executables have changed over time, and whether all active instances remain consistent. Soroban Fleet Registry indexes ledger changes to discover fleet members, resolves live WASM hashes directly from Stellar ledger state, tracks release transitions, and exposes this state through a REST API, CLI, and web interface. The service features a deterministic verification engine that classifies fleet integrity across five distinct states (HEALTHY, DRIFT, BROKEN_REFERENCE, INCOMPLETE, UNKNOWN) and strictly enforces that healthy status cannot be claimed without complete indexing coverage. Soroban Fleet Registry V1 is an entirely read-only infrastructure observer and does not deploy, own, custody, or execute contract upgrades.
