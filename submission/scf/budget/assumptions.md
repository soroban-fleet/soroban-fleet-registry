# Budget Assumptions & Financial Model

## 1. Funding Boundary

To maintain complete compliance with Stellar Community Fund rules:

- **Already Built (V1.0.0)**: All existing indexing, decoding, API, CLI, web, documentation, and testing implementations were developed prior to this application and are **NOT** eligible for retrospective reimbursement.
- **Requested Grant Funding**: Funding is requested strictly for future engineering, infrastructure hosting, testing, and operational launch across Tranches 1, 2, and 3.

---

## 2. Resource & Cost Categories

1. **Engineering (Systems / Backend)**: Implementation of indexer performance optimizations, Prometheus metrics exporter, rate-limiting middleware, bounded replay CLI, and history archive backfill in Go.
2. **Frontend & DX Engineering**: Implementation of web drift drill-down modal, export tooling, CLI JSON schemas, and documentation runbooks.
3. **Ecosystem & Developer Relations**: Conducting builder outreach, protocol onboarding, developer feedback interviews, and documentation refinement.
4. **Cloud Infrastructure & Hosting**: Production VPS/cloud instances for running continuous Stellar Mainnet and Testnet indexers, dedicated managed PostgreSQL database with automated backups, domain/DNS, and reverse proxy egress.
5. **Operational Contingency**: 5% buffer for infrastructure price variations or network RPC rate changes.
