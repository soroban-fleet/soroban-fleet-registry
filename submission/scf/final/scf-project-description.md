# SCF Project Description — Soroban Fleet Registry

Soroban Fleet Registry is an open-source indexing and verification service for Soroban smart contracts utilizing CAP-85 externally managed contract executables. CAP-85 (introduced in Protocol 28 and supported on Protocol 29) allows factory-deployed contract instances to share a single executable via an external owner contract and tag string, eliminating individual upgrade transactions. However, protocol maintainers and security reviewers lack native on-chain visibility into which contract instances share a reference, what WASM bytecode is currently active, and whether any contract instance has drifted from the expected release. Soroban Fleet Registry fills this operational gap by indexing Stellar ledger metadata to discover fleet instances, resolving live WASM hashes from persistent contract storage, and tracking historical release provenance. Its deterministic verification engine classifies fleet integrity across five distinct safety states (HEALTHY, DRIFT, BROKEN_REFERENCE, INCOMPLETE, UNKNOWN) and strictly enforces that healthy status cannot be claimed without complete indexing coverage. Soroban Fleet Registry V1 is an entirely read-only infrastructure observer and does not deploy, own, custody, or execute contract upgrades.
